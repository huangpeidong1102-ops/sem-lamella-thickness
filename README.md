# SEM 片层厚度审核软件

Windows 免安装工具，用于对带标尺的 SEM 图片进行片层厚度候选识别、三点测量和人工审核。

## 下载安装

在 [版本下载页面](../../releases/latest) 下载 `SEM_Lamella_Windows.zip`，完整解压后双击 `SEM_Lamella.exe`。请保留同目录下的 `_internal` 文件夹，无需另装 Python。图片在本机处理。

## 使用

1. 打开 SEM 图片，标记图片标尺两端，输入标尺长度和单位。
2. 根据需要选择分析区域、排除粗大组织，并选择亮相或暗相。
3. 识别片层候选，逐项审核三个测点；确认后才会计入统计。待辨区域和全范围分块用于协助人工检查。
4. 显示菜单可切换原图、灰度增强和伪彩增强，也可导出增强图片。测量使用原图，颜色仅表示明暗，不代表物相。
5. 保存工程或导出测量数据和标注图。详细步骤见 [使用说明](使用说明.txt)。

识别结果可能存在误检和漏检，无法保证标出所有不确定组织；请检查原图及待辨区域。低像素厚度尤其需要核对。增强可能放大噪声。测试范围与限制见 [测试记录](测试记录.txt)。

## 源码运行

使用 Python 3.12 或更新版本，在安装依赖后运行 `python SEM三点测量.py`。Windows 免安装包适合直接使用。仓库源码根据发布包构建前的工作版本整理，未经逐字节还原验证。
